# Introduction to Git and GitHub

## Simple Interest Calculator

A Bash calculator that calculates simple interest based on a principal amount, an annual interest rate (as a percentage), and a time period in years.

### Formula

Simple Interest = (Principal × Annual Rate × Time) / 100

### Run

```bash
bash simple-interest.sh
```

Enter the principal, annual rate, and number of years when prompted. The calculator accepts decimal inputs.

### Example

- Principal: 1000
- Annual rate: 5
- Time: 2 years
- Simple interest: 100
