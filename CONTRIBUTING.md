# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Opening issues

Before proposing a change, open an issue in the GitHub repository. For bug reports, describe the problem, provide steps to reproduce it, state the expected and actual behavior, and include relevant logs when appropriate. For ideas and enhancements, explain the proposed improvement and why it is useful.

## Submitting pull requests

1. Fork the repository and create a feature or bug-fix branch from `main`.
2. Make focused changes and test them locally.
3. Commit your changes with a descriptive message.
4. Open a pull request targeting the `main` branch.
5. Link any related issue in the pull request description, summarize your changes, and respond to review feedback.

Please be respectful and follow the project's code of conduct.
